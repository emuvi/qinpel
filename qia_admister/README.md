# AdMister

AdMister ( Administration Profession ) is a manager with all the common functionalities and the launcher of the user applications for the administration profession on the Qinpel platform.

## Modules

- **Pessoas** ([src/people](./src/people)): all the tools of information on people that a company may need (formerly the AdPeople application).
- **Vendas** ([src/sales](./src/sales)): all the tools of information on sales that a company may need (formerly the AdSales application).
